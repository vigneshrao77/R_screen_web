# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

HR professionals and recruiters.
Situation: They are processing a high volume of resumes for open positions.
Job: They need to upload resumes, select a job/criteria, start screening, see processing status, review candidates, and compare screening results to make hiring decisions.

## Product Purpose

A premium, human-designed recruiter product for screening resumes. It automates resume parsing and candidate evaluation, helping recruiters quickly identify top talent for specific jobs without dealing with technical pipeline details. Success means a recruiter can confidently make hiring decisions faster.

## Positioning

It abstracts away complex technical configurations (n8n architecture, webhooks, schemas) to provide a clean, focused, editorial-grade interface that feels like a mature enterprise product, not a developer tool or a generic SaaS dashboard.

## Operating Context

Recruiters work in a fast-paced environment where they need to process many candidates. They value clear information hierarchy, comfortable spacing, and clean tables to quickly scan candidate profiles and screening results. They do not need to see technical implementation details during their primary workflow.

## Capabilities and Constraints

Confirmed functionality:
- Upload resumes
- Select job/criteria
- Start screening
- See processing status
- Review candidates
- Compare screening results
- Settings/Admin section for technical configurations (n8n architecture, webhooks, structured schemas, credentials).

Constraints:
- Do NOT change the underlying functionality, n8n integration, routes, backend connections, database operations, and workflow integration.
- Must feel like a mature professional recruiting product.
- Avoid generic SaaS dashboard aesthetics, excessive cards, rounded corners, gradients, glassmorphism, pills/badges, AI sparkle icons, huge headings, repetitive icon boxes, unnecessary descriptions, decorative statistics.

## Brand Commitments

Sophisticated editorial/enterprise design:
- Excellent typography
- Compact but comfortable spacing
- Strong hierarchy
- Restrained colors
- Subtle borders
- Minimal shadows
- Clean tables
- Meaningful whitespace
- Clear primary actions
- Every piece of text must justify its existence.

## Evidence on Hand

Real functionality, routes, backend connections, database operations, and workflow integration are already intact in the codebase.
